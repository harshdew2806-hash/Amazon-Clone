# 🛒 Amazon Clone – E-Commerce Website UI

A visually appealing **Amazon Clone** built using HTML5 and CSS3. This project recreates the look and feel of Amazon's homepage, featuring a navigation bar, search section, shopping categories, promotional banner, and footer.

The project demonstrates my front-end web development skills, including webpage structure, styling, layouts, and user interface design.

## 🌟 Features

* 🏠 **Amazon-Inspired Homepage** – A familiar e-commerce website layout.
* 🧭 **Navigation Bar** – Includes logo, delivery location, search bar, account section, returns, and cart.
* 🔍 **Search Interface** – A styled search field with a category selector and search icon.
* 🛍️ **Shopping Categories** – Dedicated sections for clothes, electronics, furniture, beauty, pet care, toys, and fashion.
* 🖼️ **Hero Banner** – A large promotional banner at the top of the page.
* 🎨 **Interactive Hover Effects** – Visual effects on selected navigation elements.
* 📑 **Detailed Footer** – Multiple sections containing informational links and website-related categories.
* 📱 **Flexbox Layout** – Uses CSS Flexbox to organize navigation, shopping cards, and footer sections.
* ✨ **Font Awesome Icons** – Uses icons for search, location, menu, and shopping cart.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/harshdew2806-hash/Amazon-Clone.git
```

### 2. Navigate to the Project Folder

```bash
cd Amazon-Clone
```

### 3. Open the Project

Open `index.html` in your preferred web browser.

Alternatively, open the project folder in Visual Studio Code and run it using the Live Server extension.
